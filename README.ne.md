# nepali-eval (संक्षिप्त जानकारी)

> यो नेपाली पाठ मेसिन-सहायताले तयार पारिएको हो र कुनै नेपाली भाषाको जानकारले समीक्षा गरेका छैनन्।
> गल्ती भेटे कृपया सच्याइदिनुहोस् (Issue वा Pull Request मार्फत)।

यो एउटा खुला स्रोतको औजार हो जसले नेपाली भाषामा एआई (AI) ले दिएका उत्तरहरू जाँच्छ।
`१०` र `10`, वा `।` र `.` जस्ता रूपका फरकलाई गल्ती मानिँदैन। हिज्जेका वास्तविक भिन्नताहरू
छुट्टै स्वीकार्य उत्तरका रूपमा राखिन्छन्।

- २४ वटा नमुना कार्य (tasks) केवल औजार चलाएर हेर्नका लागि हुन्; यी कुनै बेन्चमार्क होइनन् र
  कुनै भाषा-जानकारले जाँचेका छैनन्।
